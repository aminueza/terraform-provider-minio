# minio_config (Resource)



`minio_config` writes a config subsystem as raw key=value data, and the
provider also has typed resources for most subsystems
(`minio_server_config_*`, `minio_audit_webhook`, `minio_logger_webhook`, the
`minio_notify_*` resources, `minio_iam_idp_*` and others). Where both write
the same setting of the same target, each apply overwrites the other's
value: `minio_config` with key `region` and `minio_server_config_region`
both set the region name, for example. Destroying `minio_config` deletes
the target its key names and resets it to MinIO's defaults, which for a
single-target subsystem like `region` is the whole subsystem the typed
resource manages. Manage a subsystem with its typed resource or with
`minio_config`, not both.

## Example Usage

```terraform
# Configure server region
resource "minio_config" "region" {
  key   = "region"
  value = "name=us-west-1"
}

# Configure API request limits
resource "minio_config" "api_settings" {
  key   = "api"
  value = "requests_max=1000 requests_deadline=10s"
}
```

## Notes

- Some configuration changes may require a MinIO server restart to take effect. The `restart_required` attribute indicates when this is necessary.
- Deleting a configuration resets it to MinIO's default for that key. It does not necessarily remove the key entirely from the server.
- MinIO returns the full subsystem configuration when reading back values (including defaults). The provider sets the `value` attribute to the full string returned by MinIO. Specify only the keys you want to manage; the diff is suppressed as long as your specified keys match the server response.

## Common Configuration Keys

- `region` — Region name. Example: `name=us-west-1`
- `api` — API request throttling and root access control. Example: `requests_max=1000 requests_deadline=10s`
- Notifications:
  - `notify_webhook:<target>` — Example: `endpoint=https://webhook.example.com queue_limit=1000`
  - `notify_kafka:<target>` — Example: `brokers=host1:9092,host2:9092 topic=events`
  - `notify_redis:<target>` — Example: `address=127.0.0.1:6379 format=namespace`

## Discovering Available Keys

Use the MinIO client to list and get help for configuration subsystems:

```bash
# List all configuration keys
mc admin config set myminio/

# Get help for a specific subsystem
mc admin config set myminio/ api
```
