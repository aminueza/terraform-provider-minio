# minio_iam_group_policy_attachment (Resource)



`minio_iam_group_policy` creates a canned policy and attaches it to a group
in one resource. Do not combine the two for the same group and policy pair,
since both manage attachment of that policy to the group.

## Example Usage

```terraform
resource "minio_iam_group" "developer" {
  name = "developer"
}

resource "minio_iam_policy" "test_policy" {
  name   = "state-terraform-s3"
  policy = <<EOF
{
  "Version":"2012-10-17",
  "Statement": [
    {
      "Sid":"ListAllBucket",
      "Effect": "Allow",
      "Action": ["s3:PutObject"],
      "Principal":"*",
      "Resource": "arn:aws:s3:::state-terraform-s3/*"
    }
  ]
}
EOF
}

resource "minio_iam_group_policy_attachment" "developer" {
  group_name  = minio_iam_group.developer.name
  policy_name = minio_iam_policy.test_policy.id
}

output "minio_name" {
  value = minio_iam_group_policy_attachment.developer.id
}

output "minio_group" {
  value = minio_iam_group_policy_attachment.developer.group_name
}

output "minio_policy" {
  value = minio_iam_group_policy_attachment.developer.policy_name
}
```
