# minio_iam_policy (Resource)



`minio_iam_group_policy` also creates a canned policy and attaches it to a
group. A `minio_iam_group_policy` with the same name manages the same
canned policy: whichever of the two is created second fails to create, so
both only end up in state after an import, and destroying either one then
removes the canned policy managed here. To attach a policy created here to
a group, use `minio_iam_group_policy_attachment`.

## Example Usage

```terraform
resource "minio_iam_policy" "test_policy" {
  name = "state-terraform-s3"
  policy= <<EOF
{
  "Version":"2012-10-17",
  "Statement": [
    {
      "Sid":"ListAllBucket",
      "Effect": "Allow",
      "Action": ["s3:PutObject"],
      "Principal":"*",
      "Resource": "arn:aws:s3:::state-terraform-s3/*"
    }
  ]
}
EOF
}

output "minio_id" {
  value = "${minio_iam_policy.test_policy.id}"
}

output "minio_policy" {
  value = minio_iam_policy.test_policy.policy
}
```
