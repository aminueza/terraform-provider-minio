# minio_logger_webhook (Resource)

Manages a logger webhook target for MinIO system log forwarding. Logger webhooks send server log events to HTTP endpoints for centralized logging.

## Example Usage

```terraform
resource "minio_logger_webhook" "splunk" {
  name       = "splunk"
  endpoint   = "https://splunk.example.com:8088/services/collector"
  auth_token = var.splunk_token
  batch_size = 100
}
```

## Existing targets

MinIO applies this target without a restart, so creating the resource fails when a target with the same name is already on the server, instead of taking it over. Import the existing target to manage it with Terraform.
