# minio_notify_kafka (Resource)

Manages a Kafka notification target for MinIO bucket event notifications.

**NOTE:** Creating a new notification target may require a MinIO server restart before it becomes fully active. The `restart_required` attribute indicates when this is necessary.

**NOTE:** MinIO applies a new notification target only after a restart, so Terraform cannot tell on create whether a target with the same name is already stored on the server. Creating this resource over an existing target merges into it and takes it over, and destroying the resource then deletes it. Check first with `mc admin config get <alias> notify_kafka`, and import an existing target instead of creating it. See [#1438](https://github.com/aminueza/terraform-provider-minio/issues/1438).

## Example Usage

```terraform
resource "minio_notify_kafka" "events" {
  name    = "primary"
  brokers = "kafka1:9092,kafka2:9092,kafka3:9092"
  topic   = "minio-bucket-events"

  sasl           = true
  sasl_username  = "minio"
  sasl_password  = var.kafka_password
  sasl_mechanism = "plain"
  tls            = true
}
```

## Schema

### Required

- `brokers` (String) Comma-separated list of Kafka broker addresses (e.g., 'host1:9092,host2:9092').
- `name` (String) Target name identifier.
- `topic` (String) Kafka topic to publish event notifications to.

### Optional

- `batch_commit_timeout` (String) How long a partly filled batch waits before it is committed; `0s` means 30s. Only used when `queue_dir` is set and `batch_size` is above 1; the plan rejects a value above `0s` without `queue_dir` or with `batch_size` of 1 or less. First available in MinIO RELEASE.2024-09-09T16-59-28Z.
- `batch_size` (Number) Number of messages to batch before sending to Kafka.
- `client_tls_cert` (String) Path to the client TLS certificate for mTLS authentication.
- `client_tls_key` (String, Sensitive) Path to the client TLS private key.
- `comment` (String) Comment or description for this notification target.
- `compression_codec` (String) Producer compression codec: `none`, `snappy`, `gzip`, `lz4` or `zstd`. First available in MinIO RELEASE.2023-12-02T10-51-33Z. Set `compression_level` with it: a codec without a level means level 0, which for gzip is no compression.
- `compression_level` (Number) Compression level for `compression_codec`. MinIO turns a value it cannot parse into 0. gzip accepts -2 to 9, where -1 is the library default. First available in MinIO RELEASE.2023-12-02T10-51-33Z.
- `enable` (Boolean) Whether this notification target is enabled.
- `queue_dir` (String) Directory path for persistent event store when the target is offline.
- `queue_limit` (Number) Maximum number of undelivered messages to queue.
- `sasl` (Boolean) Whether to enable SASL authentication for the Kafka connection.
- `sasl_mechanism` (String) SASL authentication mechanism: 'plain', 'scram-sha-256', or 'scram-sha-512'. Only used when `sasl` is `true`.
- `sasl_password` (String, Sensitive) SASL password for Kafka authentication. Only used when `sasl` is `true`. MinIO does not return this value on read; Terraform keeps the value from your configuration.
- `sasl_username` (String) SASL username for Kafka authentication. Only used when `sasl` is `true`.
- `tls` (Boolean) Whether to enable TLS for the Kafka connection.
- `tls_client_auth` (Number) TLS client authentication type (0=NoClientCert, 1=RequestClientCert, etc.).
- `tls_skip_verify` (Boolean) Whether to skip TLS certificate verification.
- `version` (String) Kafka cluster version (e.g., '2.8.0').

### Read-Only

- `id` (String) The ID of this resource.
- `restart_required` (Boolean) Indicates whether a MinIO server restart is required.

## Import

Import is supported using the target name:

```shell
terraform import minio_notify_kafka.example target-name
```

Note: `sasl_password` is not returned by the MinIO API. After import, this value will be empty in state until the next apply.
