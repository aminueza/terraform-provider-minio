# minio_notify_postgres (Resource)

Manages a PostgreSQL notification target for MinIO bucket event notifications.

**NOTE:** Creating a new notification target may require a MinIO server restart before it becomes fully active. The `restart_required` attribute indicates when this is necessary.

**NOTE:** MinIO applies a new notification target only after a restart, so Terraform cannot tell on create whether a target with the same name is already stored on the server. Creating this resource over an existing target merges into it and takes it over, and destroying the resource then deletes it. Check with `mc admin config get <alias> notify_postgres` and import an existing target instead of creating it. That command shows the config as of the server's last restart, so a target added since then is missing and one deleted since then is still listed: if the config changed since the last restart, restart the server before you check. See [#1438](https://github.com/aminueza/terraform-provider-minio/issues/1438).

## Example Usage

```terraform
resource "minio_notify_postgres" "events" {
  name              = "primary"
  connection_string = "host=postgres.example.com port=5432 dbname=minio_events user=minio password=secret sslmode=disable"
  table             = "bucket_events"
  format            = "namespace"
}
```

## Schema

### Required

- `connection_string` (String, Sensitive) PostgreSQL connection string (e.g., 'host=localhost port=5432 dbname=minio user=minio password=secret sslmode=disable'). Read back from the server.
- `format` (String) Output format for event records: 'namespace' or 'access'.
- `name` (String) Target name identifier.
- `table` (String) Name of the PostgreSQL table for event records.

### Optional

- `comment` (String) Comment or description for this notification target.
- `enable` (Boolean) Whether this notification target is enabled.
- `max_open_connections` (Number) Maximum number of open connections to the PostgreSQL database.
- `queue_dir` (String) Directory path for persistent event store when the target is offline.
- `queue_limit` (Number) Maximum number of undelivered messages to queue.

### Read-Only

- `id` (String) The ID of this resource.
- `restart_required` (Boolean) Indicates whether a MinIO server restart is required.

## Import

Import is supported using the target name:

```shell
terraform import minio_notify_postgres.example target-name
```

Note: The import reads `connection_string` back from the server, so it is in state after the import, even though it is marked sensitive.
