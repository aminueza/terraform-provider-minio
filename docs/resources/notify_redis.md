# minio_notify_redis (Resource)

Manages a Redis notification target for MinIO bucket event notifications.

**NOTE:** Creating a new notification target may require a MinIO server restart before it becomes fully active. The `restart_required` attribute indicates when this is necessary.

**NOTE:** MinIO applies a new notification target only after a restart, so Terraform cannot tell on create whether a target with the same name is already stored on the server. Creating this resource over an existing target merges into it and takes it over, and destroying the resource then deletes it. Check with `mc admin config get <alias> notify_redis` and import an existing target instead of creating it. That command shows the config as of the server's last restart, so a target added since then is missing and one deleted since then is still listed: if the config changed since the last restart, restart the server before you check. See [#1438](https://github.com/aminueza/terraform-provider-minio/issues/1438).

## Example Usage

```terraform
resource "minio_notify_redis" "events" {
  name     = "primary"
  address  = "redis.example.com:6379"
  key      = "minio-events"
  format   = "namespace"
  password = var.redis_password
}
```

## Schema

### Required

- `address` (String) Redis server address (e.g., 'localhost:6379').
- `format` (String) Output format for event records: 'namespace' or 'access'.
- `key` (String) Redis key name used to store or publish event records.
- `name` (String) Target name identifier.

### Optional

- `comment` (String) Comment or description for this notification target.
- `enable` (Boolean) Whether this notification target is enabled.
- `password` (String, Sensitive) Password for Redis authentication. MinIO does not return this value on read; Terraform keeps the value from your configuration.
- `queue_dir` (String) Directory path for persistent event store when the target is offline.
- `queue_limit` (Number) Maximum number of undelivered messages to queue.
- `user` (String) Username for Redis ACL authentication.

### Read-Only

- `id` (String) The ID of this resource.
- `restart_required` (Boolean) Indicates whether a MinIO server restart is required.

## Import

Import is supported using the target name:

```shell
terraform import minio_notify_redis.example target-name
```

Note: Sensitive fields are not returned by the MinIO API. After import, these values will be empty in state until the next apply.
