# minio_server_config_site (Resource)

Manages the MinIO site configuration (site name and region). The site subsystem replaces the legacy region subsystem managed by `minio_server_config_region`; when `region` is set here it takes precedence over the legacy region for the region MinIO reports.

## Example Usage

```terraform
resource "minio_server_config_site" "main" {
  name    = "dc1-rack2"
  region  = "us-east-1"
  comment = "Primary datacenter"
}
```

## Schema

### Required

- `name` (String) Site name (e.g., "dc1-rack2").

### Optional

- `comment` (String) Comment or description for the site configuration.
- `region` (String) Region of the site (e.g., "us-east-1"). When set, it overrides the legacy `region` subsystem for the region MinIO reports. Removing the attribute or setting it to "" clears the site region.

### Read-Only

- `id` (String) The ID of this resource.
- `restart_required` (Boolean) Whether a MinIO server restart is required.
